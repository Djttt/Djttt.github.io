实验室 GPU 资源长期存在「排队靠吼、环境靠抄、数据靠运气」的问题。本项目建设了一套 Web 化的算力调度与训练环境平台，覆盖从**申请、交付、使用到回收**的完整生命周期。

## 训练环境标准化

基于 Docker 制作 **CUDA + PyTorch 基础镜像**，集成 SSH、JupyterLab、tmux 等工具，新实例即开即用，杜绝逐台配环境的重复劳动。

## GPU 资源调度

实现 GPU **整卡分配**：支持单次申请 1–8 张卡，自动完成容器创建、节点调度与访问端口配置，快速交付训练环境。

## 多卡训练支持

为训练实例配置 **16Gi 共享内存**与**独立持久化存储**，支撑多卡训练与数据长期保存，避免容器重启造成训练数据和模型权重丢失。

## 资源管理与自动回收

实现 GPU 使用情况实时统计、训练实例预约及**到期自动释放**；支持节点资源查看与任务冲突检查，显著提高集群资源利用效率。

## 平台管理与数据运维

基于 **FastAPI + Vue 3** 实现资源申请、实例管理、工作区下载与扩容、跨实例数据迁移及操作记录，支持 GPU 使用时长统计，为成本核算提供数据依据。
